# 规则备选池索引

本目录是**备选池**，不是生效位。生效位是 `rules/active/`，由
`python -m super_agent.rules_init` 从本目录复制过去。

- `candidates/rules/` 与 `candidates/skills/` 保留两级：挑的时候需要知道类别。
- `rules/active/` 扁平：挑完只剩「生效 / 不生效」一个维度。
- 池里只放**脱敏后**的入池件。不抽的 9 份不落盘。

> 本文刻意不写出被替换的私有标记原文：本目录的判据是这些标记零命中
> （见第五节）。规则的原文与逐条实测留私有方案单，不随开源仓分发。

## 三、`<机器N>` 的读法

`<机器N>` 按行独立编号：同一行内 N 不同＝不同机器，N 相同＝同一台。**跨行不共享编号。**

`<机器N>` 只表示「原文此处有一个机器代号」，**不承诺 N 跨行一致**。

行内编号会带来一处语义偏差，已知并接受：`rules/long_output.md` `:18` 是「同一台机器
的两个平台目录」，按行编号后读作两台机器。上下文里的 `/tmp` 与 `%TEMP%` 已足够说明
平台差异，不为这一行做特例。

## 四、运行期目录引用待人工映射，不自动替换

## 五、门禁

入池件必须让 `python tools/privacy_gate.py` 保持 rc=0（全仓干净，不给本目录开豁免）。

另有四条与门禁**无关**的独立判据，命令与实测在私有方案单里给（本文不写出被检查的
标记原文——写出来就会让本目录自己命中）：

1. 私有模型供应商名、私有协作工具名、私有节点清单文件名：零命中。
2. 主机绝对路径（盘符开头）：零命中。
3. POSIX 主机绝对路径（系统目录开头）：零命中。
4. 运行期目录引用：**允许**保留，见第四节；这一条是人工映射项，不是零命中项。

第 1–3 条由 `tools/privacy_gate.py` 的 `PATTERNS` 在本目录上跑一遍即可复核。
