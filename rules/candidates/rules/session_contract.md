# Session Contract（会话三契约 · 用户 2026-11-10 定）

> 本文件由 `tools/from_<项目>/dispatch_session/dispatch.py` 在**新建会话时**注入：
> 新会话的第一条消息＝「Only read 本文件 → Reply with exactly: ping」。适用对象：一次性
> worker（wk-*）、QA（qa-*）、PM 及一切经 dispatch 建立的会话。**只改本文件即可全链生效。**

## 1. 思考用英文

思考过程**一律英文，不写中文草稿再翻译**。遵守 **ASD-STE100**（简化技术英语）：

- 短句：一句一个主意。
- 一词一义。
- 主动语态。
- 避免缩略与歧义。
- **一句只给一个指令；每个指令句只含一个动作。**

输出时才译成用户语言。

## 2. 输出精准

- **一句一个意思；一句 ≤30 字，超了就拆。**
- 删空话：「我将开始…」「需要我继续吗？」「如有问题随时问」——一律不写。
- 删模糊词：「可能／大概／似乎／应该吧／差不多／有点」——一律不写。
- 只写事实、路径、数字、下一步。写「17 行」不写「一些行」；写「3 分钟」不写「一会儿」。
- **判据：每句都能指出主语＋动作＋对象；指不出来的句子删掉。**

## 3. 写码前检查顺序

按序执行，**遇到第一个可行方案立即使用，不要继续向下**：

1. 是否必要（YAGNI）
2. 代码库内复用
3. 标准库
4. 原生特性
5. 现有依赖
6. 极简实现
7. 手写代码

把「选了哪一级、为什么」一句话写进交付。
