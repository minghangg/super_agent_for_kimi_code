# 子代理使用规则（2026-10-12 用户定）

> 目的：**减少 token 消耗**。纯执行型任务不让主模型逐字做，也不让子代理反复试错烧钱。

## 1. 适用范围（**必须**派单个子代理的任务类型）

- 纯代码开发／调试／测试类
- 抓取类、低等开发任务（机械、步骤明确、不需要产品判断）
- **只读取证／勘查类**（2026-10-16 用户定）：跨机／跨仓／接口上「查事实」—— 查版本、查进程、查路由、比对文件哈希、翻台账某条。**判据：答不出「≤2 次工具调用」就派出去。**
- **例行起步／收口类**（2026-10-16 用户定）：新会话按清单读若干文件、跑既有自检条目、把交接文档搬进 `done/`、逐条复跑一份既定判据并取回原始输出。**只搬运与执行，不判定**；判定、落盘、归档仍归主模型。**注意**：被派者与写代码的人不得是同一个（§5「同一时间只有一个会话动代码」）。

**非适用**（留在主模型）：方案撰写、评审、需要取舍拍板的、涉及密钥/生产动作编排的。

## 1.1 取证类的硬要求（**原件必须回流，结论归主模型**）

> 由来（2026-10-16 实录）：问「<机器1> 的 <模型供应商> 是否已更新」—— 主模型裸 `ssh` ＋ `curl` 探了 **8 轮**，还混入一次**错误推断**（把 `/admin/*` 的通用 `401` 当成「路由存在」的证据，又花 3 轮自纠），纯取证内容全留在主上下文里。这类活该派出去。

1. **任务书写死**：目标主机／仓库／端口、**逐条命令**、要求的输出形态、**失败即停**（同一套口径见 §2 第 2／4 条）。
2. **输出契约**（不合格 ⇒ 退回重跑）：子代理必须回四件 ——
   ① 每条结论依据的**命令原文** ② 该命令的**原始输出**（不许摘要、不许只写「正常」）③ 一句结论 ④ **失败／不确定项单列**。
   **只给结论不给原始输出 ⇒ 不合格**（主模型不得把无法复看的说法转述给用户）。
3. **一律只读**：不得写文件、停启服务、推分支、改任何状态；**不得打印任何密钥值**（只许程序化调用）。
4. **结论归主模型**：子代理的回件是**输入**，不是判据。**独立复核／验收类不靠它** —— 角色层 `.kimi/skill/supervisor.md` §6「自己复跑关键判据、不采信自述」是**本职**，派出去只是把「自述」从一层挪到另一层。⇒ 允许的分工是：**子代理跑命令、贴原始输出；判定与结论仍由主模型下**。
5. **能用紧凑工具就别派、也别裸探**：如 `fleet_status.py` 这类一次给全机队快照的工具优先用；不要拿一串 `ssh` 手搓。

## 2. 执行口径

1. **单一子代理**：一次只派一个，不并行铺子代理。
2. **无思考模式**：子代理一律 thinking off；因此主模型给的方案必须**写到无需判断**（逐条命令、逐字文件内容、每步的预期输出与停止条件）。
3. **输出要求**：直接开发、减少废话——按计划完成既定内容即可，不写过程感想。
4. **遇障碍即反馈**：子代理碰到方案外的阻塞（命令失败、前提不符、权限不足）⇒ **停止并如实汇报**，由主模型解决；**不许子代理自己不停尝试**（主模型在方案里给每个关键步骤写清"失败就停"）。

## 3. 子代理模型优先顺序

| 优先级 | 供应商 | 模型 |
|---|---|---|
| 1 | <模型供应商> | deepseek v4.1 flash |
| 2 | DeepSeek-new | deepseek v4.1 flash |
| 3 | kimi | k3 256 |

排前的不可用（限流/报错/超时）⇒ 用下一个。**当前实况**：<模型供应商> 的 dsp v4.1 在限流（2026-10-11 起），故现走第 2 档。

## 4. 边界：**不得动方案外的任何路径**（2026-10-12 用户定）

1. 子代理只许改动任务方案里**点名落盘**的文件/目录；**严禁**移动、删除、清空、重写任何方案外路径——**哪怕目的是让门禁变绿**。
2. 别人的在飞文件挡住验收（例：未跟踪产物让 `--check` 变红）⇒ **停下来汇报**，由主模型处置（协调/错峰/豁免）；**不得** `mv`/`rm`/`sed`/`chmod` 别人的文件，也不得用「先挪走跑完再挪回」这类变通。
3. 跑**带清空行为的构建**（如 `rm -rf web/app`）前必须先 `git status` 核工作区：发现非本任务的改动 ⇒ 停下汇报。
4. **反面案例（2026-10-12 实录）**：子代理为让 `build_seo --check` 变绿，把别人未跟踪的 `content/books/zhouyi-yaoyi/`（223 个文件）`mv` 到 `/tmp` 打算跑完挪回——主代理停止该子代理时险些造成**永久丢失**（未跟踪文件不进 git、不进回收站；已由主代理人工找回）。

## 5. 与既有规则的关系

- 方案细化稿的写法参照已执行的两例：W1/W2 书籍翻译（`agent-2`）、卡带 React 壳修复（方案 `classics_carousel_homepage_react_shell_stale_shows_11` 的「评审与细化执行方案」节——含 S0–S6 逐步命令＋逐字文件附件）。
- 同一时间只有一个会话动代码、发布归发布执行人（子代理默认**不做** deploy）等既有纪律不变。
