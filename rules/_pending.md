# 规则议案缓冲（`rules/_pending.md`）

> **只放「待定」的提案**（用户 2026-10-29 定）。已裁定的（采纳／丢弃／挂起）**一律移出本文件**——历史在台账，回滚点在 `backup/`。
> 规则改动先写这里；**未获用户点头不许改实体**。用户当面下的指令可直接落地，并在历史记「用户明令」。
> 为什么要有缓冲：规则不是越多越好，要考虑 agent 的上下文预算。提案必须写「改哪／为什么／净增行数／判据」，能合并或删除的优先。

## 提案格式

```
### P<n> · <一句话标题> · <日期> · 状态=待审
- 改哪：<文件:行或节>
- 为什么：<效率／质量／成本／可维护>＋量化代价
- 净增：+<n> 行 / −<m> 行（净 <±k>）
- 判据：<改完怎么复跑验证>
```
